# El Mundo de los Caballeros

Sitio web dedicado al universo de **Saint Seiya (Los Caballeros del Zodíaco)**: una galería interactiva con los caballeros de Bronce, Plata y Oro, sus fichas y características.

---

## 🔗 Ver el sitio en vivo

Recorré el sitio completo **desde cualquier dispositivo** (celular, tablet o computadora), sin descargar nada:

**👉 [https://griaya.github.io/saint-seiya/](https://griaya.github.io/saint-seiya/)**

## 📂 Ver el código

El proyecto completo (HTML, CSS, JavaScript y datos) está en el repositorio:

**👉 [https://github.com/griaya/saint-seiya](https://github.com/griaya/saint-seiya)**

## 💻 Cómo verlo en tu computadora

El sitio es 100 % estático: no necesita servidor, instalación ni conexión a internet.

1. Descargá o cloná el proyecto.
2. Hacé doble clic en `index.html`.
3. Se abre en tu navegador con todas las imágenes y funciones.

## ☁️ Guardar y abrir en Google Drive

Google Drive sirve para **guardar y compartir** el proyecto, pero no para verlo como página web (Drive no ejecuta HTML). Para verlo correctamente:

1. Descargá el ZIP recibido en tu mail a tu computadora.
2. Para verlo, descomprimilo.
3. Hacé doble clic en `index.html`.

> ⚠️ **Importante:** no abras solo el archivo `.html` suelto. Necesitás la carpeta completa (con `css`, `js`, `data` e `img`) o se romperán los estilos e imágenes.

## 🛠️ Tecnologías

- **HTML5**
- **CSS3**
- **JavaScript puro** — sin frameworks ni dependencias externas
